# 學員工具與註冊訂閱

已核准且不在密碼重設流程時，入口隱藏介紹、帳戶審核區、隱私說明與 STEP 流程，直接顯示學員工具。保留序曲教材、線上調香台、學員原料購買三個入口；移除原料筆記與課後補充卡片。管理員仍可由工具列進入審核；待審核者仍看得到資格狀態，未開放工具權限。

使用者確認註冊後自動訂閱，並同意首次告知與同意流程。新版註冊同意說明包含氣味通信的課程、活動與新品消息及取消方式；metadata 只多記錄 newsletter_consent_version=2026-10-29，不作授權判斷。註冊時先記錄偏好，Auth 確認信箱後，資料庫自動以該帳戶已驗證的 Email 與申請姓名加入現有 email_subscribers 名單。不採用客戶端傳入的訂閱收件 Email。

不補入舊版註冊、未驗證信箱、沒有新版訂閱告知紀錄的帳戶。已存在的同 Email 訂閱保留原姓名與偏好，不重複新增。註冊訂閱不代表學員資格核准，原訂單權限仍獨立檢查。

已驗證帳戶可以在待審核帳戶畫面或工具列取消氣味通信，只影響本人目前已驗證信箱。取消後即使後續登入或信箱驗證事件再執行，也不會自動重新加入。完整偏好表在私有 schema，匿名與學員都不能直接讀取；公開 RPC 僅回傳本人是否訂閱，或取消本人訂閱。

本次只串接現有訂閱名單，不寄送歡迎信、不建立 Resend 行銷群發、不傳送歷史訂閱名單給第三方。前端取消功能失敗不會顯示成功，訂閱查詢失敗不阻擋學員工具。

驗證包含：註冊／信箱驗證前後、重複 Email、舊版無訂閱告知、匿名／跨帳戶權限、取消後不自動恢復、登入後隱藏介紹與審核流程、註冊 metadata 及取消控制。尚未建立新的真實測試學員或寄出實際驗證信。

部署：apply_migration 連續回傳 Invalid or expired requestState，已確認未套用後，改以 execute_sql 在單一交易套用本 SQL。正式查詢確認表及 RPC 已存在，匿名不能查詢、學員不能直接讀偏好表或呼叫內部訂閱 helper。沒有執行既有學員補入；Supabase migration history 不含本次直接交易，版本來源以 supabase/student-newsletter.sql 為準。

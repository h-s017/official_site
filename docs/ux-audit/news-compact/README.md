# 首頁最新消息精簡列表｜2026-10-24

使用者核定「四大服務 → 最新消息 → 品牌／藝術家介紹」順序，首頁最多三則，以日期／標題為主，摘要至多兩行。本批手機摘要一行、其他兩行；完整內容與原網址保留在消息內頁，未修改消息、課程、價格或付款資料。

## 實作

- HTML直接安排消息在藝術家介紹之前，備援快照及即時CMS共用同一列表樣式。
- 首頁data-news-layout=list跳過舊橫向輪播／克隆與注入樣式；其他使用舊元件的頁面維持原流程。
- 首頁上限改三則，保留原兩個月日期篩選與CMS排序，因此測試時即時資料為兩則；離線及no-JS快照仍為既有三則。
- 標題為可辨識連結，點擊區延伸至整列，至少44px；更多消息維持/news/。取消固定卡片高度與橫滑。
- 修正site.js會強制把消息搬回品牌介紹後方的舊排序；局部清除卡片負邊距及hover位移，避免列表超出容器。
- 標題手機16px／其他17px，摘要16px／1.6行高，日期13px；輔助文字#666、摘要#555，News標籤對比一併改善。限定首頁列表，不全面覆寫共用UI。

## 測試與限制

Playwright 1.62／Chromium154／axe-core4.10.3。四viewport加三種資料／備援情境，共7/7。檢查實際DOM順序、列表與頁面無水平溢出、無輪播／克隆、觸控高度、焦點、摘要行數、標題連結目的地、四viewport消息區axe零違規。另以五筆長標題與長摘要測試上限三則；API失敗與no-JS保留快照及相同位置。只攔截測試回應，無後台資料修改；消息連結導向測試頁，不載入預約或付款。

測試過程發現並修正舊腳本搬移、負邊距、News小字4.41:1對比；最終結果見after-results.json。無Lighthouse、CrUX或RUM數據，不宣稱效能／CLS／全站WCAG通過；消息變動可能仍改變頁面高度。no-JS／離線快照有時效差異，沿用既有快照策略。

# Brand font subsets

Unmodified Latin WOFF2 subsets from the same Google Fonts CSS versions used by the site:

- Cormorant Garamond v21, variable weights 400–700: https://fonts.gstatic.com/s/cormorantgaramond/v21/co3bmX5slCNuHLi8bLeY9MK7whWMhyjYqXtK.woff2
- Noto Serif TC v37, variable weights 400–900: https://fonts.gstatic.com/s/notoseriftc/v37/XLYgIZb5bJNDGYxLBibeHZ0BtnAOSA.woff2

Their SIL Open Font License files are included beside the fonts. Remaining Unicode subsets continue to use fonts.gstatic.com URLs in style.css. Local hosting and preload remove the late Latin/digit font swap without changing the brand families or synthesizing replacement fonts.

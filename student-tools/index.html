申請資料與隱私說明

姓名、Email、手機及所選課程僅供藏花香徑工作室核對學員身分、管理帳戶與必要訂單聯繫，不會自動加入行銷名單。帳戶驗證及資料儲存由 Supabase 處理，網站程式碼由 GitHub 託管，申請資料與密碼不會寫入 GitHub。密碼由驗證服務處理，審核人員無法查看密碼。

資料於學員服務及必要紀錄保存期間使用。你可透過 LINE @hscent 或 hanascent@gmail.com 申請查詢、更正、停用或刪除；未提供必要資料將無法核對學員資格。詳見隱私權政策。
